SIMPLE_JSON_TEXT

Unicode-correct string text: emoji-safe escaping and decoding (0.2.0)
← Home Overview API Examples

Overview

SIMPLE_JSON_TEXT escapes text into the content of a JSON string literal and decodes it back, for every Unicode code point. Since 0.2.0 every put_string, add_string, json_string, string_item and as_string_32 goes through it.

It exists because the underlying ejson library gets two things wrong:

  • A character beyond the Basic Multilingual Plane - every emoji, e.g. U+1F916 - was written as a five-digit \u1F916, which is not JSON and which ejson's own decoder read back as U+1F91 followed by 6. Non-ASCII text now goes out as raw UTF-8, which RFC 8259 requires every consumer to accept.
  • A surrogate-pair escape (\ud83e\udd16, as emitted by Python's json, older Java and JSON.stringify) was decoded as two lone surrogates. The pair is now combined into the one character it encodes.
How it was found: SIMPLE_JSON_OBJECT.put_string's value_stored postcondition failed the moment a chat message beginning with the robot emoji was stored (2026-08-29). Contracts caught it; independent vectors now pin it.

API Reference

FeatureDescription
escaped (a_text): STRING_8The literal's content for a_text: quote, backslash and controls escaped; everything else raw UTF-8. Postcondition: decodes back to a_text.
decoded (a_literal): STRING_32The text a literal's content denotes: standard escapes, \uXXXX with surrogate pairs combined, raw UTF-8; a byte that is none of these is kept as Latin-1 rather than lost.
json_string (a_text): JSON_STRINGAn ejson string value escaped here, not by ejson.
unescaped (a_json): STRING_32The text an ejson string denotes, surrogate pairs combined.

Examples

create o.make o.put_string ({STRING_32} "%/0x1F916/ shalom", "s").do_nothing -- o.string_item ("s") is the same 8-character string; its first code is 0x1F916 -- o.to_json_string carries the emoji as four raw UTF-8 bytes: F0 9F A4 96

Vectors: testing/test_unicode_text.e (astral round trip, surrogate escapes, controls, U+10000 and U+10FFFF).
